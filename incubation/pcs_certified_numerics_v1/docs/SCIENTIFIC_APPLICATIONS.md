# Scientific applications (mathematical models only)

Demonstrations are **mathematical**. They do not validate physical adequacy or clinical safety.

1. **Roots:** `x²−2` isolation on `[0,2]` — `examples/roots/`
2. **Optimization:** `(x−1)²` global bounds — `examples/optimization/`
3. **ODE:** linear decay `x'=-x` enclosure via certified exp — tests
4. **Thermo:** finite energy levels partition function — tests
5. **Markov:** two-state reachability — tests
6. **Uncertainty:** interval parameters via expression boxes — CLI `prove-interval`
