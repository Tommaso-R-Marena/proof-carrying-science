# Reviewer instructions

1. Obtain package directory with `intake.lock.json`, `evidence_bundle.json`, `acceptance_policy.json`.
2. Pin your own acceptance policy (do not trust producer PASS).
3. Run `python -m pcs_next_v1.cli review PACKAGE --policy POLICY`.
4. Inspect assurance card HTML/JSON.
5. Record time-on-task and friction in the feedback instrument.
