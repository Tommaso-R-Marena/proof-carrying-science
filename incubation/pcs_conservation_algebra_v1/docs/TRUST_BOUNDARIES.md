# Trust boundaries

| Trusted for proved claims | Untrusted | Explicitly OPEN |
| --- | --- | --- |
| Lean theorems on stoichiometric algebra | Producer contracts, heuristics, proposed γ | Continuum ODE accuracy |
| Python checker recomputation | Host `float` diagnostics | Empirical / biological validity |
| Exact `Fraction` arithmetic | Any producer `verdict` field | PCS package authority |
| Declared finite network bounds | Submitted Lean/Python source (never run) | Clinical / regulatory acceptance |

Signed PCS packages, Ed25519 roots, and Claim IR are out of scope for v1.
