# External lab — LIMITATIONS

- This package is evaluation infrastructure, not a certification program.
- Fixtures under `reviewer_adoption/` are synthetic unless stated otherwise.
- Workbench tools never issue `ACCEPT` / `PASS`.
- Blind-challenge ground truth is for protocol software tests; it is not human
  performance data.
- Tabletop exercises must not alter real credentials or live infrastructure.
- Completing the checklist does **not** equal completed external laboratory
  validation of PCS.
- Network policy, export control, and IRB/ethics constraints are lab-specific and
  out of scope for this kit.

Forbidden outcome state: `EXTERNAL_VALIDATION_COMPLETE` — this kit does not claim completed external laboratory validation.
