# Independent scientific pilot (synthetic external lab)

This example is the public/synthetic stand-in used by:

- `pcs independent-pilot-v1`
- `scripts/run_independent_scientific_pilot_v1.py`
- `scripts/run_cleanroom_independent_pilot_v1.py`

It stages a laboratory-authored restricted one-compartment IV-bolus PK + direct-Emax PD workflow from `examples/pkpd_one_compartment`, freezes claims before attestation, confirms discovery against that intake lock, and produces a Lean-authoritative evidence package for second-environment review.

See `docs/INDEPENDENT_SCIENTIFIC_PILOT_V1.md`.

**Non-claims:** no external partnership, legal clearance, biological adequacy, clinical validity, or production signing custody.
