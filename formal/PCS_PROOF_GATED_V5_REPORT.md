## 2. Exact worst-case interval error (Priority 2) — `PCS/V2/ProofGatedRobust.lean`

**Setting.** `WideNet` is \(f(x)=c+\sum_{j=1}^{n}a_j\max(0,w_jx+b_j)\), with all parameters
in `Int`, any width \(n\) and any magnitude. The target \(t\) is also a `WideNet`.
`errAt f t x = |f x − t x|` (as a `Nat`).

**Algorithm.** `kinks` comes from `ProofGatedNoForget`. A unit with \(w \ne 0\) contributes
\(q-1, q, q+1\) with \(q = (-b)/w\) (Lean's `Int` division, which rounds toward
\(-\infty\) for positive divisors and is the Euclidean quotient in general). A unit with
\(w = 0\) contributes nothing.
`probes K L U = L :: U :: K.filter (· ∈ [L,U])`, and

```lean
def maxAbsErr (f t : WideNet) (L U : Int) : Nat :=
  if L ≤ U then maxOver (errAt f t) (errProbes f t L U) else 0
```

**Proof structure.**
1. `relu_secondDiff_of_not_kink`: away from \(q-1,q,q+1\), the three pre-activations
   \(w(y\pm1)+b\) and \(wy+b\) have the same sign. The proof writes \(-b=wq+r\) with
   \(0\le r<|w|\) and covers negative \(w\) and exact-zero activations. So each unit, and
   every `WideNet`, has zero second difference there (`predict_secondDiff`).
2. `affine_of_secondDiff`: zero second difference on the interior of an integer interval
   implies that the function is affine on it.
3. `abs_le_endpoints`: on an affine piece, \(|g(x)|\le\max(|g(l)|,|g(r)|)\).
4. `probe_dominates`, the general certificate theorem. **For any** `g : Int → Int` and
   any list `K` such that `g` has zero second difference at every interior point outside
   `K`, every \(x\in[L,U]\) is dominated by some probe. Singleton cells are handled: if
   \(x\) is itself a probe, it dominates itself.

**Main theorems** (no hypotheses beyond those shown):

```lean
theorem maxAbsErr_isMax (f t : WideNet) (L U : Int) (hLU : L ≤ U) :
    (∀ x, L ≤ x → x ≤ U → errAt f t x ≤ maxAbsErr f t L U) ∧
      ∃ x, L ≤ x ∧ x ≤ U ∧ errAt f t x = maxAbsErr f t L U
theorem maxAbsErr_le_iff (f t : WideNet) (L U : Int) (B : Nat) :
    maxAbsErr f t L U ≤ B ↔ ErrBound f t L U B
theorem findErrViolation_sound (f t L U B x) (h : findErrViolation f t L U B = some x) :
    L ≤ x ∧ x ≤ U ∧ B < errAt f t x
theorem findErrViolation_complete (f t L U B)
    (h : ∃ x, L ≤ x ∧ x ≤ U ∧ B < errAt f t x) : ∃ x, findErrViolation f t L U B = some x
theorem robustB_iff (a m t : WideNet) (L U : Int) :
    robustB a m t L U = true ↔ ∀ B : Nat, ErrBound a t L U B → ErrBound m t L U B
theorem robustB_iff_pointwise : robustB a m t L U = true ↔
    ∀ x, L ≤ x → x ≤ U → ∃ y, L ≤ y ∧ y ≤ U ∧ errAt m t x ≤ errAt a t y
theorem findRobustViolation_sound (a m t L U x) (h : findRobustViolation a m t L U = some x) :
    L ≤ x ∧ x ≤ U ∧ ∀ y, L ≤ y → y ≤ U → errAt a t y < errAt m t x
theorem maxAbsErr_congr : (∀ x ∈ [L,U], predict f x = predict f' x) → (… t, t' …) →
    maxAbsErr f t L U = maxAbsErr f' t' L U
theorem errProbes_length (f t L U) : (errProbes f t L U).length ≤ 3 * (width f + width t) + 2
```

Here `ErrBound f t L U B := ∀ x, L ≤ x → x ≤ U → errAt f t x ≤ B`. For an empty interval
(\(L>U\)) the checker returns `0`, every bound holds, and `findErrViolation` returns `none`.

**Edge cases.** These are covered by the theorems for all inputs. They are also exercised
at runtime against brute force in `fixtures/proof_gated/robust_vectors.tsv`: 311 cases,
including zero weights, negative weights, breakpoints at exact integers, negative
divisors, a singleton interval, an empty interval, intervals near \(\pm10^{12}\), and
weights near \(10^9\). The kernel `decide` proofs in §3 evaluate the checker on
\([-10^9,10^9]\).

## 3. The unified strong gate (Priority 3) — `PCS/V2/ProofGatedStrongGate.lean`

```lean
structure StrongSpec where
  arch : Arch; target : WideNet; corpus : List Int; lo : Int; hi : Int
def acceptStrong (S : StrongSpec) (a m : WideNet) : Bool :=
  accept S.corpusSpec a m && noForgetting a m S.target && robustB a m S.target S.lo S.hi
def StrongAdmissible (S : StrongSpec) (a m : WideNet) : Prop :=
  admissible S.corpusSpec a m ∧                                         -- A
  (∀ x : Int, predict a x = predict S.target x → predict m x = predict S.target x) ∧ -- B
  (∀ B : Nat, ErrBound a S.target S.lo S.hi B → ErrBound m S.target S.lo S.hi B)    -- C
theorem acceptStrong_iff (S : StrongSpec) (a m : WideNet) :
    acceptStrong S a m = true ↔ StrongAdmissible S a m
```

`admissible` is unchanged from `ProofGatedGeneric`. It requires:
* both models valid for the architecture bound;
* corpus correctness preserved;
* at least one newly correct corpus input;
* strictly smaller natural-valued corpus loss.

The gate is therefore **sound and complete for exactly A ∧ B ∧ C**. No objective was
redefined.

**Chains and adversarial schedules.** `StrongTrace S n a b` is the type of chains of
\(n\) strongly accepted steps. The following are proved:
* `strongTrace_noForget`, `strongTrace_robust`, `strongTrace_maxAbsErr`;
* `strongTrace_loss : loss b + n ≤ loss a`;
* `strongTrace_valid`, `strongTrace_corpus`;
* `no_long_strongTrace`.

For an arbitrary proposal function `proposer : Nat → WideNet → WideNet`, which may depend
on the step index and the current model (adaptive or adversarial):

```lean
theorem runStrong_trace (proposer) (k i m) :
    StrongTrace S (countStrong S proposer i k m) m (runStrong S proposer i k m)
theorem countStrong_le_loss (proposer) (k i m) : countStrong S proposer i k m ≤ loss S.corpusSpec m
theorem runStrong_guarantees (proposer) (k i m) : let r := runStrong S proposer i k m
  (∀ x, predict m x = predict S.target x → predict r x = predict S.target x) ∧
  (∀ B, ErrBound m S.target S.lo S.hi B → ErrBound r S.target S.lo S.hi B) ∧
  loss S.corpusSpec r + countStrong S proposer i k m ≤ loss S.corpusSpec m ∧
  (S.corpusSpec.valid m = true → S.corpusSpec.valid r = true)
```

Semantics-preserving rewrites commute with the gate: `acceptStrong_congr_candidate`,
`acceptStrong_congr_incumbent` and `acceptStrong_perm_invariant`.

**Does the strong gate still allow multi-generation improvement?** Yes, but whether it
does depends on the interval. These are checked facts on the 3-unit target `target3`
(= `gen3`):

* `growth_chain_narrow`: the original chain `gen0 → gen1 → gen2 → gen3` passes on
  \([-4,4]\). Worst errors are 5, 5, 4, 0.
* `growth_step1_rejected_mid`: on \([-50,50]\) its first step is **rejected**. Adding
  `relu(2x+1)` alone raises the worst error from 51 to 96. The extracted witness is
  \(x=50\). On \([-10^9,10^9]\) the worst error would rise from \(1000000001\) to
  \(1999999996\) (`growth_chain_errors`).
* `robust_chain_wide`: a different **3-generation chain passes on \([-10^9,10^9]\)**:
  `gen0 → r1 = [relu(-2x)] → r2 = [relu(-x+1)] → gen3`.
  * Worst errors: \(1000000001 \ge 999999999 \ge 5 \ge 0\).
  * Corpus losses: \(34 > 26 > 19 > 0\).
  * Step 2 *replaces* the hidden unit; step 3 grows the width from 1 to 3.

**Each requirement is independently necessary** (checked):
* `blindForget_only_B`: accepted by A and C on \([-4,4]\), rejected only by B (witness
  \(-12\)).
* `ood_only_C`: corpus-perfect and loses no correct integer, so it is accepted by A and
  B. On \([-50,50]\) its worst error is 1440 against 96, so it is rejected only by C
  (witness 50).
* `noProgress_only_A`: a permuted copy passes B and C but makes no progress.

The same `oodCandidate` **passes** the strong gate on \([-4,4]\) (see
`strong_gate_cases.tsv`). The robustness guarantee covers only the stated interval.

## 4. Generalized architectures (Priority 4) — `PCS/V2/ProofGatedDeepCert.lean`

For `DeepNet`, the per-unit breakpoints of §2 are not available, because later layers'
breakpoints depend on earlier layers. I therefore use a **proof-carrying certificate**:
a strictly increasing list \(L=p_0<\dots<p_n=U\).

**Checking a cell `[p, q]`.** The checker propagates (value at \(p\), slope) pairs exactly
through all layers (`affv`, `neuronStep`, `layerStep`, `hiddenStep`). For each neuron with
pre-activation \(P+eS\), \(0\le e\le d=q-p\):
* if it is \(\ge0\) at both ends, ReLU is the identity on the cell;
* if it is \(\le0\) at both ends, ReLU is 0;
* if \(d=1\), any behaviour is affine on the two integer points (exact slope
  \(\mathrm{relu}(P+S)-\mathrm{relu}\,P\));
* otherwise the cell is rejected.

**Theorems:**
```lean
theorem cellCoeffs_spec (m : DeepNet) (l d A B : Int) (h : cellCoeffs m l d = some (A, B)) :
    ∀ e, 0 ≤ e → e ≤ d → predict m (l + e) = A + e * B
theorem certMaxErr_isMax (f t : DeepNet) (L : Int) (rest : List Int)
    (h : chainOK f t L rest = true) :
    (∀ x, L ≤ x → x ≤ lastPt L rest → derr f t x ≤ certMaxErr f t L rest) ∧
      ∃ x, L ≤ x ∧ x ≤ lastPt L rest ∧ derr f t x = certMaxErr f t L rest
theorem certErrBound_iff (h : chainOK f t L rest = true) (B : Nat) :
    certMaxErr f t L rest ≤ B ↔ DErrBound f t L (lastPt L rest) B
theorem cert_exists (f t : DeepNet) (L U : Int) (h : L ≤ U) :
    ∃ rest, chainOK f t L rest = true ∧ lastPt L rest = U
theorem cert_must_contain (f t : DeepNet) : ∀ rest p, chainOK f t p rest = true →
    ∀ z, p < z → z < lastPt p rest → ¬ SecondDiffZero (predict f) z → z ∈ rest
theorem deepRobustCert_sound / deepRobustCert_complete, acceptDeepCert_sound
```

The certificate format is therefore:
* **sound** for any certificate;
* **never stuck**: the full enumeration is always valid (`cert_exists`);
* **complete relative to valid certificates**: `deepRobustCert_complete`;
* **inherently size-bounded below**: every interior point where the network's second
  difference is nonzero must appear (`cert_must_contain`).

**Characterised limitation (checked instance).** `saw6 = sawtooth [16,8,4,2,1]` has 6
hidden layers of width 2, with weights and biases in \([-16,16]\). It has nonzero second
difference at **all 63** interior integers of \([-32,32]\) (`sawtooth_all_kinks`).
Therefore every valid certificate on \([-32,32]\) contains all 63 points
(`saw6_cert_contains_all`). It is the full enumeration.

The construction folds \(|x|\) repeatedly, and the number of pieces doubles with each
fold. **I have only checked this instance.** The general statement (\(2^{k+1}-1\)
mandatory points for \(k+1\) layers) is not proved here. It is consistent with the known
exponential growth of linear regions in deep ReLU networks. Thus:
* exact, interval-size-independent verification is proved for depth 1 (§2);
* for deeper networks I only claim a sound certificate checker whose cost is linear in
  the certificate size, together with a proof that small certificates cannot exist in
  general.

`dFull_cert` shows the good case. A 5-point certificate covers \([-10^6,10^6]\) for a
2-hidden-layer network, and `dFull_bad_cert` shows that a cell crossing a second-layer
breakpoint is rejected.

**Not addressed:** multi-input (finite-dimensional) domains. The one-dimensional
cell/endpoint argument does not transfer directly. In \(\mathbb Z^d\) the linear regions
are polytopes, and the maximum of an affine function on a polytope's lattice points is
not determined by finitely many "endpoints" without solving an integer program.

## 6. Trusted assumptions (not modelled, therefore not proved)

* Reading bytes from storage, symlink policy (the `PGSI1` CLI follows symlinks, as tested),
  file-system atomicity of compare-and-swap, durability and rollback protection.
* Cryptographic hashing, signatures, protected storage, process isolation.
* Faithful execution of a served network by any runtime other than Lean's own `predict`.
  (`infer` is proved equal to `predict` of the decoded network; an external runtime is
  a separate obligation.)
* The Lean kernel, the Lean 4.28.0 compiler (used only by runtime tests and the CLI, not
  by any theorem), and the three standard axioms listed in §1.
* Legacy `PGSI1` byte-equality for negative parameters assumes that the opaque string
  append is concatenation. This is an explicit hypothesis, not an axiom.

## 7. Computational complexity

Let \(N\) be the total number of hidden units of the networks involved, and assume
unit-cost big-integer arithmetic. In reality cost grows with bit length, not with
\(U-L\).

| checker | probe points | cost |
|---|---|---|
| `maxAbsErr`, `findErrViolation`, `robustB` (§2) | \(\le 3N+2\) (proved: `errProbes_length`) | \(O(N^2)\) arithmetic operations, independent of \(U-L\) |
| `findForgetting` (`ProofGatedNoForget`) | \(\le 5(3N+1)\) (by construction; not stated as a theorem) | \(O(N^2)\) |
| `acceptStrong` | corpus gate \(O(\lvert\text{corpus}\rvert N)\) + the above | polynomial in network and corpus size |
| `chainOK` (deep certificate, §4) | certificate length \(c\) | \(O(c\cdot P)\), where \(P\) is the number of network parameters |

The deep certificate length has a proven lower bound: the number of interior points with
nonzero second difference. On the checked sawtooth instance this equals the interval
size, so no certificate can be smaller than the interval.

## 8. Counterexamples and limitations (all kernel-checked)

* **Corpus gate alone:**
  * `ProofGatedLimits.blind_extension_accepted` and `multilayer_ood_regression`: units
    inactive on the corpus change held-out predictions arbitrarily;
  * `local_trap`: all 20 single-parameter edits are rejected although a 3-parameter edit
    to a perfect model is accepted.
* **No-forgetting is non-regression, not generalisation:** `ood_not_forgetting`.
* **Robustness only holds on the stated interval:**
  * `oodCandidate` passes the strong gate on \([-4,4]\);
  * `growth_step1_rejected_mid` shows that a natural growth path can be blocked on wider
    intervals, so stronger guarantees can remove improvement paths.
* **Termination is unavoidable:** `gated_run_stabilizes` and `countStrong_le_loss`. Every
  run makes at most `loss initial` changes, and then the system is frozen. Under these
  gates there is no unbounded self-improvement; the guarantee is bounded, monotone
  progress.
* **Depth:** certificates can be forced to full size (`saw6_cert_contains_all`).

## 9. Open problems

1. Prove the sawtooth lower bound for every depth \(k\) (\(2^{k+1}-1\) mandatory points
   for \(k+1\) hidden layers of width 2). Ideally, also prove that deciding
   "\(\max_{[L,U]}|f-t|\le B\)" for deep integer networks is coNP-hard under binary
   encoding of \(L,U\).
2. Find an efficient *certificate generator* for deep 1-D networks: symbolic breakpoint
   propagation, whose output size equals the true number of pieces, checked by `chainOK`.
3. Extend to multi-input domains, for example boxes in \(\mathbb Z^2\) with
   activation-region certificates plus per-region integer-programming certificates.
4. A no-forgetting checker for deep networks over bounded intervals (the `rootFrom`
   trick per certified cell).
5. Model the storage/CAS/signature layer and prove the end-to-end statement relative to
   explicit storage axioms stated as hypotheses.

**On the general research question.** What is proved is the following. A self-modifying
system that changes the parameters and *architecture* (unit count, unit replacement)
of one-input integer ReLU networks can be gated by an executable check with these
properties:
* the check accepts exactly the steps that improve a finite benchmark, lose no correctly
  handled integer anywhere, and do not raise the exact worst-case error on a stated
  interval;
* all of these guarantees compose over arbitrarily long, adversarially proposed runs;
* the guarantees carry through to the exact bytes committed and the predictions served.

These are compositional, executable guarantees outside the training examples, but they
are relative to a fixed target network and a fixed interval. They say nothing about
targets the system was not given, and every run halts after at most `loss initial`
accepted changes. Nothing here supports a claim about general intelligence.
