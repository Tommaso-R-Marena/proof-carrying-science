This is not an exhaustive screen-reader or all-page accessibility audit.

## Games, data and genuine model updates

Both existing game catalogs and adult CC0 opt-in remain intact. Export quality is derived from server replay, separating partial/full trajectories, archive checks, independent kernel replay, hints, undo and invalid actions. Authenticated consent does not prove humanity or independent decision-making. The existing holdout and training/utility split remain mandatory.

One explicitly **synthetic** browser session completed the actual proof, was consented into D1, exported under Owner authorization, and passed fresh Lean transition/proof replay. Six checked action states trained the 14,773-parameter MemoryNetwork for two epochs (**12 gradient steps**); all 30 named tensors in the training receipt changed and a real candidate checkpoint was saved. There was **no held-out transfer evaluation** and no promotion. Zero genuine human trajectories were collected. This demonstrates a working game-to-learning pipeline, not human-data efficacy.

Withdrawal deleted active donations and exported membership identifiers in a receipt. Importing that receipt into the lineage ledger quarantined the export, derived dataset and checkpoint; a subsequent preflight rejected future use. Checkpoint bytes remained unchanged. This is ledger-aware future-use control, not model unlearning or global deletion of distributed copies/backups. Copy custodians retain separate obligations.
