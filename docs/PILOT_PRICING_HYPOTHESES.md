# Pilot Pricing Hypotheses

These are hypotheses for customer discovery, not fixed prices.

## Free design-partner alpha

Use sparingly for 1–3 strategically useful partners when the primary value is learning and obtaining a credible external case study.

Conditions:
- tightly bounded workflow;
- permission to use anonymized lessons learned or a case study if mutually agreed;
- explicit feedback meeting.

## Paid fixed-scope pilot

Initial hypothesis: price the engagement around the value of expert assurance work, not per-seat SaaS economics.

Possible structure:
- fixed workflow and claim inventory;
- defined artifact count / adapter scope;
- evidence package + report;
- one review meeting;
- optional custom adapter priced separately.

Do not promise regulatory acceptance or universal verification.

## Later enterprise model

Potential commercial value can come from:
- private/on-prem deployment;
- organization-wide policy and CI orchestration;
- validated domain adapters;
- access control / audit history;
- integrations;
- support and SLA;
- commercial assurance engineering.

The open trust root should remain independently inspectable.
