# PCS checked iterative training v1

The protocol and partitions are written before training. Verified collection is freshly replayed; candidate checkpoints are frozen before final evaluation. Selection uses validation solve count and expansions only. The new end-to-end theorem feeds a separately checked/licensed intake, alpha-duplicate holdout firewall and next checkpoint gradient updates. Two additional predeclared tasks retain 2/2 proofs before and after. Repeated training is executed; persistent measurable improvement is not established. Public benchmark tasks are not private blind evaluation.
