# First 90 Days

## Days 0–30 — Establish the truth boundary

**Technical**
- Pin Lean toolchain and compile the assurance kernel.
- Specify certificate canonicalization and trust boundary.
- Harden the Python reference verifier against malformed/adversarial packages.
- Implement environment/container identity.
- Begin PK/PD restricted workflow representation.

**Research**
- Write definitions/threat model for the Proof-Carrying Scientific Workflows paper.
- Convert CertiForge/CASMI lessons into abstract case-study requirements without copying un-cleared source.
- Define verification vs validation terminology rigorously.

**Company**
- Complete IP/provenance matrix.
- Run first 10 customer interviews.
- Speak with university tech-transfer/legal resources about research ownership and publication sequencing.
- Keep company name/branding provisional; validate problem first.

## Days 31–60 — Build the biopharma wedge

**Technical**
- PK/PD domain pack prototype.
- Unit-safe quantities and model-parameter contracts.
- Restricted equation-to-code correspondence prototype.
- Generate PDF/HTML-style assurance report from the certificate data model.
- GitHub CI prototype on one controlled scientific repository.

**Research**
- Claim-evidence invalidation semantics.
- Adversarial attacks and falsification benchmark.
- First paper architecture/results sections.

**Company**
- Interviews 11–25.
- Select 2–3 design partners only if a repeated paid pain point is clear.
- Draft pilot scope: one workflow, one evidence package, measurable review/reproducibility benefit.

## Days 61–90 — Falsify product-market and research claims

**Technical**
- Run first real external or semi-external workflow through the system.
- Measure false accepts, false rejects, human-review burden, and integration time.
- Formal proof replay for at least one nontrivial obligation.

**Research**
- Freeze a paper claim ledger: proved / experimentally supported / open.
- Produce a reproducible artifact and independent rerun instructions.

**Company**
- Complete 25–30 interviews.
- Decide: continue biopharma wedge, narrow further, or pivot based on evidence.
- Only then finalize company entity/licensing/fundraising decisions.

## Day-90 success criterion

Not valuation, press, or a large feature count.

Success means:

1. a machine-checkable kernel with a defensible trust boundary;
2. one serious biopharma workflow producing a useful evidence certificate;
3. at least one customer class confirming a costly assurance problem;
4. a research manuscript with claims that survive adversarial review;
5. clear IP ownership/publication status.
