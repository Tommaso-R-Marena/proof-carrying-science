# Operational Lean release v1

The Worker journals public checker requests in the existing D1 audit storage. A client retry retains one request identity, quota admission and dispatch attempt. An uncertain accepted dispatch is reconciled by polling; it is never blindly retransmitted. Immutable, hash-linked events contain ticket metadata and source hashes, not source text, IPs or bearer tickets. The original public quotas remain two per IP per rolling day and twelve globally.

Queued, running, verifying, complete, failed, cancellation, expiry and resource exhaustion stay distinct. Only exact approved workflow logs with bounded source-correlated receipts can produce proof evidence. Owner diagnostics expose bounded metadata. Archive reconciliation repairs missing archive records after an interrupted write. GitHub availability and deployment remain external trust dependencies; hashes alone do not prove execution.

The browser saves the consented statement, idempotency key and acknowledged ticket in session storage for the current tab. Resume is explicit; forgetting browser metadata never cancels a job. Cancellation is requested against a uniquely bound workflow and is confirmed only by its terminal provider state. Storage is not proof authority.

The core emits finite, ordered source-correlated operational events. Parent CPU time is measured separately from child Lean work; unavailable counters are not invented. The optional prospective-hybrid-v2 public mode executes the same attributed portfolio as the local hybrid CLI, independently replays a winning proof and never trains or promotes a checkpoint automatically.

`PCS Owner Hosted Qualification` executes ten fixed diagnostic cases on standard public GitHub runners, at most two concurrently. Each really invokes Lean; completed proofs and counterexamples receive independent replay. It covers valid hybrid/learned/human paths, ambiguous/unsupported statements, forged proof and goal mutation rejection, and bounded unresolved search. These authored controls are operational qualification, not a held-out capability benchmark. They exercise zero public Worker admissions and cannot substitute for ten real public admission flows. Public quotas are never bypassed.

Local evidence includes actual workerd SQLite concurrency/restart tests, real browser UI tests with explicitly fixture-backed provider responses, and successful diagnostic commands for human actions, counterexample replay and one-expansion unresolved search. Final provider qualification and deployment evidence are recorded separately after protected integration.
