# Research receiving trust boundary

| Layer | Established property | Remaining trust or obligation |
|---|---|---|
| Pure canonical decoder | General roundtrip on supported contracts; accepted bytes exactly re-encode | Structural resource domain; existing decimal codec and standard Lean axioms |
| Pure scientific receiver | Every accepted byte/result pair has checked state semantics, conservation and bounds | Restricted exact A→B mathematics; no empirical model adequacy |
| Lean executable path | Main passes the received byte list directly to `receive` | Compiler/runtime, framing, JSON rendering and host IO correspondence are tested, not proved |
| Python reference | Independent manual scanner and per-step rational replay | Finite differential evidence, not general refinement |
| Process wrapper | Fixed operator command, pre/post pins, same-byte snapshot, bounded child IO, exact result comparison | Operator configuration, host Python/OS/storage, transitive inventory review; transient substitution remains possible |
| Signed receipt | Real Ed25519 authenticates exact receipt bytes under separately supplied key | Ephemeral key has no independent identity until externally pinned; no execution-occurrence proof |
| Scientific support | Mathematical, computational and empirical scopes remain distinct | Synthetic data provide no physiological or empirical validation |

The process is separately launched, not independently administered. No protected
credential, trusted storage appliance, independently operated witness, immutable
root, measured loader, or verified compiler has been provisioned in this session.
Hashes, Python object privacy, file permissions, locks and process separation do
not remove those assumptions.

`qualify.py` compiles the new library and queries its actual theorem environment.
Its declared-module inventory includes direct and transitive imports resolved to
object/IR files, plus toolchain shared libraries. This improves reproducibility
and operator pinning; it is not a measurement of every OS-loaded object. Local
qualification explicitly uses previously qualified, source-identical dependency
objects, freshly checking all new proofs without modifying another worktree.
Hosted Lake qualification separately checks the normal pinned project build.

The original PR153 receiver regression is not hidden by these new results.
Its independent audit is draft #155 and its separate repair is draft #154.
The old head remains historical evidence, including its twenty unwritable
negative receipts. Critical unresolved regressions still block promotion.
