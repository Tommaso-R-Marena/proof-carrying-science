# Scoped scientific receiver assurance composition

This research adapter binds the `PCS-SCI-BOUND-V1` multi-step A→B case to the existing HECK sticky-falsification engine and actual PCSNext proof-obligation graph. It does not define a universal lattice, convert another calculus into Lean authority, or change production verification.

`research/scientific_receiver_v1/assurance.py` accepts immutable raw model bytes, a receiver-owned exact SHA-256, bounded typed scientific assumptions and explicitly synthetic boolean observations. It independently replays the model using the existing exact Python reference. Its optional operator-controlled Lean harness actually sends those same bytes to the configured executable and compares protocol, raw-byte echo and every returned mathematical field. No caller-supplied verdict, verifier callback, report or assurance rank is accepted. This harness is research execution evidence; selecting a file path is not an independently protected authority root.

The current positive fixture has three firings `[1, 2, 1/2]`, initial state `(10,0)`, final state `(13/2,7/2)`, declared A box `[6,7]`, A claim `[5,8]` and transferred B claim `[2,5]`. The adapter preserves the full exact replay result rather than relying on the fixture's label or a producer PASS flag. False environment evidence rejects even if the caller recomputes its raw digest.

## Separate evidence dimensions

| Dimension | What this adapter records | What does not follow |
|---|---|---|
| Formal mathematics | Conditional `PCSScientificReceiver.verifiedWireSound` source identity and local source-module hashes | A fresh kernel audit or a general theorem about the host implementation |
| Executable correspondence | Optional actual Lean process observation with exact response comparison | Compiler/IR/import, IO/OS or protected-execution attestation |
| Artifact integrity | Recomputed exact raw SHA-256 equality | External authenticity or empirical provenance |
| Computational reproducibility | Independent exact rational transition replay and enclosures | Empirical model adequacy |
| Numerical uncertainty | Exact enclosure inside the declared finite discrete model | Measurement error, continuum accuracy or arbitrary kinetics |
| Causal identification | No claim | A causal-effect conclusion |
| Empirical validation | Not established; observations are explicitly synthetic controls | External scientific evidence |
| Authenticated history | Not established | Trusted chronology, signer authority or complete governance history |

All reports retain `scientific_acceptance=false`, `production_authority=false` and `promotion_authority=false`. They are research observations, not accepted production certificates. Report hashes are version-local deterministic identities, not PCS JCS identities or signatures. Python objects and returned dictionaries are not security boundaries.

## Assumption and observation binding

Each assumption includes its identifier, exact subject raw SHA, statement, predicate and exact boolean prediction. HECK derives the prediction identity from all these values and the subject-bound theory identifier. Each synthetic observation must name that exact artifact, assumption and prediction key. Changing the subject, predicate or statement invalidates the old observation binding. Unknown producer status, authority or rank fields reject through the exact typed schemas. Numeric or string coercions to booleans reject.

The adapter calls HECK's actual `observe_against_prediction` and `discharge_sticky`. HECK may internally label a matching observation `empirically_supported`; the adapter exposes that original internal label but grants **no empirical validation**, because these inputs are synthetic controls. This is an experimental adapter with explicit scope, not a proof that HECK labels and PCSNext statuses are equivalent.

## Practical falsification and preserved facts

The actual PCSNext graph contains independent exact-computation evidence, declared assumption obligations, dependent prediction obligations and scientific applicability. A scoped contradiction invokes `ProofObligationGraph.invalidate_from` using the affected HECK prediction key. The actual reverse cone reopens the assumption, its dependent prediction and overall scientific applicability. An unrelated assumption's prediction remains conditional.

For the positive three-step fixture, a synthetic observation contradicting `closed_compartment=true` reopens those applicability obligations. It does not change the exact `(13/2,7/2)` calculation, invalidate the mathematical theorem, or imply an experimental discovery about a real compartment. These are separate dimensions. A later matching synthetic observation cannot restore the falsified prediction: the adapter uses HECK's sticky operation and the graph stays open. Repeated contradictions are retained as observations and remain idempotent with respect to the reopened set.

The graph intentionally does not make the independent finite mathematical computation depend on physical adequacy. The model-to-world applicability obligations do depend on the scientific premises. No graph status is interpreted as production acceptance, and no strongest-rank aggregation grants science or authority.
