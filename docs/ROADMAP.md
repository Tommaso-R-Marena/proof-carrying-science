# Roadmap

## Phase 0 — Founding architecture (now)

- domain-neutral claim/evidence model;
- deterministic certificates;
- artifact hashing;
- workflow DAG checks;
- first domain checks;
- adversarial tests;
- mission/open-core/business documents.

## Phase 1 — Research-grade kernel

- compile and prove Lean acceptance semantics;
- define certificate JSON canonicalization formally;
- build proof replay adapter for Lean artifacts;
- environment/SBOM capture;
- signed certificates;
- stronger workflow IR;
- provenance graph and claim invalidation;
- first paper draft.

## Phase 2 — Computational biopharma pilot

- PK/PD restricted DSL / equation-to-implementation mapping;
- unit-safe model contracts;
- numerical error and solver reproducibility adapters;
- omics/MS split/leakage and replicate-aware evaluation pack;
- GitHub CI integration;
- first 3-5 design-partner audits.

## Phase 3 — Enterprise plane

- identity/roles;
- policy engine;
- private deployments;
- audit dashboard;
- evidence retention;
- workflow system integrations;
- quality/regulatory reporting support;
- commercial support/SLA.

## Phase 4 — Cross-domain packs

AI agent assurance, chemistry/reaction-network verification, medical-device computational modeling, aerospace/energy, and other critical sectors only after the core semantics are stable.

## Institution-building milestones

Revenue milestones should trigger research independence rather than only sales expansion. Example policy to consider later: allocate a fixed fraction of gross profit or operating budget to openly publishable research once sustainability thresholds are met.
