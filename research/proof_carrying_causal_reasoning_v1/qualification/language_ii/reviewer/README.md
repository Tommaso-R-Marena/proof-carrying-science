# Separately authored text challenge

The coordinator froze 72 examples before the implementation agent disclosed its parser. The public language families were known to both. The fixture crosses three invented pairs of names, two assignments of rates, two contrast directions and six prompt families. The programmer did not receive the cases or labels before parser lock. The scoring process passes only the three public text fields to each solver. Full digests of cases and parser are checked at replay. The families share templates, so the counts describe this finite exercise. They do not support an independent-binomial population interval.

Of 36 answerable cases the new parser answered 24 correctly, with no wrong sign. All twelve fair-coin paraphrases were answerable but drew abstentions. It also abstained on all 36 cases requiring abstention for possible confounding, missing arm probabilities, or unresolved positivity. The Phase I parser abstained on all 72. Missing treatment information cannot establish non-identification in every causal model. These labels specify whether a sign is justified from the given assumptions.

From the repository root run `python -m research.proof_carrying_causal_reasoning_v1.qualification.language_ii.reviewer.replay`. Compare its result to `results.json`. The independent scorer uses no model or API. These fixtures are public after this evaluation.
