# Exact marginal inference

The baseline conditional-probability query returned 3 for (P(X=0\mid X=1)) when (P(X=1)=1/4). Overwriting a conflicting evidence bit creates the wrong numerator. Contradictory assignments now give zero after the denominator passes the positivity check.

The ordinary `BinarySCM.p_obs` path now retains only assignments to processed variables with unprocessed children. At step i a retained weight sums prefix masses consistent with observations so far. Multiplying by each binary mechanism and summing out variables at their last use maintains this invariant. Mechanism probabilities are still validated on parent configurations of probability zero. This argument assumes fixed, pure stochastic mechanisms. This Python implementation has differential tests but no machine-checked refinement to Lean.

The independent reference materializes the complete joint distribution. The differential test checks 60 generated DAGs (2 through 6 nodes, four edge densities, three seeds) with observational, single-intervention and double-assignment variants. The deployment path still has exponential worst-case time and space in the width of its chosen order. A dense parent table alone can require exponential work.

Run `python -m pytest -q research/proof_carrying_causal_reasoning_v1/tests/test_frontier.py`, then `python -m research.proof_carrying_causal_reasoning_v1.qualification.benchmark_frontier` from the checkout root. The stored 12-case benchmark covers 5, 8 and 10 nodes, fan-in 1 or 3, with and without an intervention. All probabilities agreed exactly. For the 10-node, fan-in-3 observational example, full enumeration took 91.155 ms and the frontier method 0.513 ms. Measurements are single local observations, subject to concurrent load. Traced Python allocation peaks are separate from wall timing and omit native process memory. The algorithm uses established exact sum-product elimination.
