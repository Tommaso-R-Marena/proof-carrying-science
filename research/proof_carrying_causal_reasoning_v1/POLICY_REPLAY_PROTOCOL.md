# Policy identification replay protocol

Freeze before inspecting differential outcomes. This experiment checks a mathematical implementation on synthetic finite populations. It does not estimate external scientific accuracy.

1. Use two exhaustive grids specified as (strata, actions, maximum population size): (2, 2, 3) and (2, 3, 2). For every positive size up to each maximum, enumerate **all multisets of full unit types** and all deterministic policies. A unit type contains its stratum, natural assignment and a Boolean response at every action. Collapse each population to a sorted multiset of factual triples. Compute its intervention count by running its response vectors at the policy actions.
2. For each factual multiset and policy, retain the exact set of counts and at least one complete witness for each. Submit every ordered pair of proposed interval endpoints from zero through population size plus one, inclusive. Compare the receiver with the enumerated set. Submit all ordered pairs of attainable point values with their independently found models, including equal pairs. Reverse one model's row order to test full-multiset equivalence.
3. Independently compare exact rational success rates in followers and nonfollowers in each occupied stratum. Require at least one follower, with no restriction from an empty nonfollower group. Partition models by that oracle. Submit feasible balanced models and target mutations, and submit incompatible assumption witnesses wherever the enumeration found one. Record unsupported or infeasible observational contexts separately.
4. Include directed tests for unsupported actions or strata, inconsistent model rows, response-mask range, intervention substitution, assumption-mode substitution, integral-grid infeasibility, empty data, malformed fields, and separately supplied study/proposal alignment. Include a positive example with unequal stratum sizes and a target distinct from the pooled follower rate. Fail immediately on any decision disagreement.
5. Run the pinned Lean build, declaration axiom probes, and replay command in POLICY_IDENTIFICATION.md. Publish the output with counts and this protocol's SHA-256 digest. All cases are implementation checks chosen by the research authors. No held-out language or SOTA claim follows.
