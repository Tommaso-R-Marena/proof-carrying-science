## A finite delayed-authorization census

Each reviewer decision concerns whether a proposed action, if applied, would violate an inert ledger's policy at settlement. The actual dispatcher uses a conservative canonical action. Every proposal remains in the evaluation. A different permitted choice can disagree with the dispatcher. Three ledgers use distinct authorization structures.

| Ledger | Registers A, B at submission | One-bit settlement event E | Available proposals and authorization | Canonical execution |
| --- | --- | --- | --- | --- |
| exhibit | owner and editor signatures, each 0 or 1 | embargo cleared | Keep always. Synopsis with either signature. Facsimile with both signatures and clearance. | Synopsis with either signature, else keep |
| allocation | regular tokens A and provisional tokens B, each 0, 1 or 2 | provisional tokens vested | Observe always. Reserve one or two units if their total can be paid from vested and regular tokens. | Reserve one when A is positive, else observe |
| recital | original seat A (0 left, 1 right) and pending swap B (0 or 1) | swap confirmed | Rest always. Either chair is usable exactly when it matches the final seating chart. Only a pending, confirmed swap exchanges chairs. | Rest while a swap is pending, else original chair |

Cross every legal A, B, E and proposal with two irrelevant notes ("ordinary", "review") and four independent packet-loss schedules (omit proposal, A, B, or E). This is 102 semantic episodes, 816 equally weighted packet records and no historical model responses. The generator serializes only observations, packet ID and erasure schedule. An operational adjudicator in a separate module constructs a settlement ledger from the complete packet and checks a posting, consuming tokens, or occupying a seat. Labels are held in a separate answer key keyed by ID. Redundant renderings increase no independent sample size.

The public examples use flat records. The evaluation uses nested two-event records, upper case and padded action/annotation strings; detectors share one specified adapter for this documented wire schema. Report exact counts for executed action only, proposal plus execution, early submission registers, settled telemetry, and settled telemetry with a known single erased field. The note accompanies each view. Comparators flag disagreement (abstain on missing proposal), flag the word "review", or apply the policy only with all registers. The candidate enumerates public legal completions compatible with the view, including the canonical dispatch action. It issues a verdict exactly when all compatible policy decisions agree, else abstains. No comparator can read IDs, erasure schedules, answer keys, other held-out rows or generator-only flags. All receive the identical decoded fields and the same static policy and finite state bounds, with a common ceiling of 54 completion checks per observation (the largest ledger). Adjudication is a separate implementation of the same authored specification. There is no external adjudicator.

For each view count TP, TN, FP, FN, positive abstentions and negative abstentions for all methods. Also compute the minimum deterministic full-coverage error and the maximum zero-error coverage by partitioning held-out observations by exact equality and consulting labels only after predictions. Cross-check the candidate against this hindsight ceiling. Record family-specific confusion, temporal refinement and loss effects. These are finite population quantities. There are no sampling intervals. No fitting on either schema is planned.

## Repeated use of a small qualification panel

This separate simulation gives a complete probabilistic model for noisy binary authorization instruments. The latent target on each case is a fair coin. Conditional on that target, the incumbent and each candidate independently report the correct answer with a specified constant probability. These synthetic instrument readings do not come from the ledger experiment. Incumbent accuracy is 3/4. Run both a weaker-challenger arm (11/16) and an equal-quality control (3/4). Fix 256 independent pseudorandom replicates per arm, 32 qualification cases and 256 independently drawn final cases per replicate. Vary challenger prefix length K over 1, 4, 16, 64. Each prefix experiment starts from the original incumbent. The lowest challenger index wins challenger ties. An incumbent tie retains the incumbent.

1. Reused-panel selection uses the challenger with maximum full-panel accuracy if it strictly beats the incumbent.
2. Split confirmation nominates the best challenger on the first 16 only if it strictly beats the incumbent, then promotes exactly when that single nominee also strictly beats the incumbent on the second 16. The confirmation score cannot change the nominee. Each prefix experiment is a separate counterfactual, and no confirmation or final feedback reaches the candidates or later nominations.

Both methods have access to the same 32 qualification cases and identical instrument predictions. Final cases are generated from disjoint deterministic streams only after choosing every prefix winner. Report the paired final accuracy change, promotion counts, mean difference in panel and final scores, simulation sampling error, and exact population expectations for independent Bernoulli instruments. Distinguish repeated selection optimism from actual degradation when candidates have equal true quality. This design tests two explicit procedures under the same maximum budget, without tuning panel size or promotion thresholds.

Reproduction uses Python's standard library. The master seed for independently domain-separated streams is `pcs-220-qualification-ii-18983`. Freeze the protocol, generator, adjudicator, evaluation packets and answer-key hashes before scoring. This is a public holdout after the first evaluation. Deterministic local hashes prove reproducibility; the coordinator receives the freeze digest before scoring. Public source and hashes supply no long-term access control.
