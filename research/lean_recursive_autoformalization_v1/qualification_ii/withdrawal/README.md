# Which conclusions survive the withdrawal of evidence?

A reviewer supplies possible interpretations, a target predicate, and the groups of observations on which each interpretation agrees. Multiple measurements sharing a source belong in one trust group. The research question is whether a conclusion survives removal of any k groups. This applies to a causal consequence under an assumed model, a proposed action under a policy, or a mathematical statement relative to a reference. Each instance carries exactly one domain and subject. The result quantifies over the specified hypotheses and evidence partition.

If no interpretation fits the complete observations, the receiver returns INCONSISTENT. Otherwise an interpretation can become compatible after at most k withdrawals exactly when it disagrees with at most k groups. The disagreeing groups themselves give a minimum withdrawal witness. Thus a robust verdict needs every contrary interpretation to disagree with more than k groups. This reduces the decision from enumerating possible withdrawal masks to scanning the interpretation-by-group matrix. Time is linear in the number of cells for a fixed budget if the matrix is represented with constant-time cell access. The simple Lean wire adapter indexes lists and has an additional width factor.

The theorem `minimum_for_world` applies to arbitrary types of hypotheses and groups with a Boolean agreement relation. `check_exact` quantifies over all withdrawal predicates of the specified budget. It includes a consistent anchor in its premises for a robust result. Removing groups never invalidates that anchor. The checker first rejects repeated group IDs on the wire; the Lean examples show how counting two copies of a source can otherwise create a false appearance of corroboration. Supplying two *different* IDs for the same source still requires a reviewer to detect their common provenance.

From this directory, run `python3 replay.py` with Lean 4.28.0 on PATH and compare with `results.json`. It recompiles the proof and wire reader in a fresh directory. A separate Python procedure exhaustively enumerates the withdrawal masks and checks each returned counterinterpretation. Across 123 matrices and 731 budgets it obtained 158 robust verdicts, 337 counterexamples and 236 inconsistent cases. Eight malformed matrices were rejected. The proof closures use propext and Quot.sound.

In the three small examples, a causal risk contrast survives withdrawal of one source, a contextual routing verdict survives none, and a Boolean reference comparison survives two. These margins reflect the supplied source-group partition. They are sensitivity claims about finite models. An omitted interpretation, a false study assumption, or a wrongly separated common source can invalidate their application. The wire reader does not authenticate source custody or establish population coverage. It expects finite local inputs; limits checked after reading a line are not process-level resource isolation. The approach is a formal application of minimum conflict sets, related to the established hitting-set approach to diagnosis. [Reiter, A Theory of Diagnosis from First Principles](https://doi.org/10.1016/0004-3702(87)90062-2)
