# EvidenceKernel v27 — anytime calibration and prospective drift falsification

**Status: isolated PCS research-only verifier.** No Lean proof of the implementation, external witness, physical randomness validation, prospective clinical test, or production authority.

This module extends v26 with (1) an exact finite-mixture e-process for one-sided Bernoulli propensity calibration that remains valid at arbitrary registered calibration stopping points without per-look Bonferroni spending; (2) an independently computed, pathwise drift *alarm* for later study assignment rates; (3) a fail-closed bridge to v25's fixed-cohort, anytime-valid treatment-effect verifier; and (4) exact integer/rational, independently implemented Python/Node.js replay and adversarial controls.

**Result on same synthetic calibration data with 16–512 permitted looks:** v26 conservative ceilings `[0.701,0.517,0.570]` versus v27 `[0.691,0.509,0.561]`. Conditional synthetic lower ATE bound improves from about 0.1704 to 0.2034 at the *same* 7% overall error budget. These are not empirical or biological findings. When sample size is known fixed in advance, v26's fixed-sample Clopper–Pearson bound may outperform v27.

Run from PCS repository root (Python ≥3.12 and Node ≥20):

```
python -m unittest discover -s research/evidencekernel_anytime_calibration_v27 -p 'test_*.py' -v
DIR=research/evidencekernel_anytime_calibration_v27
python -m research.evidencekernel_anytime_calibration_v27.kernel \
  "$DIR/example_contract.json" "$DIR/example_records.json" \
  "$DIR/example_study_protocol.json" "$DIR/example_study_records.json" \
  --contract-pin "$(cat "$DIR/example_contract_pin.txt")" \
  --records-pin "$(cat "$DIR/example_records_pin.txt")" \
  --study-pin "$(cat "$DIR/example_study_pin.txt")" \
  --evidence-pin "$(cat "$DIR/example_evidence_pin.txt")"
node "$DIR/independent.js" \
  "$DIR/example_contract.json" "$DIR/example_records.json" \
  "$DIR/example_study_protocol.json" "$DIR/example_study_records.json" \
  "$(cat "$DIR/example_contract_pin.txt")" \
  "$(cat "$DIR/example_records_pin.txt")" \
  "$(cat "$DIR/example_study_pin.txt")" \
  "$(cat "$DIR/example_evidence_pin.txt")"
```

The CLI reports `CONDITIONALLY_REJECTED` when the synthetic inference rejects its registered null and **no drift alarm occurs**. That status is conditional on physical premises and is not a scientific certificate. If the declared e-process detects a drift anomaly, the report returns `DRIFT_ALARM_NO_CLAIM`.
