# Verified truth, disclosure channels and canonical completion

## Finding and scope

**A correctness-only gate does not establish confidentiality.** A model can in
principle encode a private bit in two representations of the same true count, in
whether it publishes, or in which approved query it selects. Twenty-two ordinary
Lean theorems establish these counterexamples, an arbitrary finite verified
representation channel, and the positive scheduled-release result. No new axioms,
admitted proofs or native proof shortcuts. Sixty-seven general inventories are
checked across the new22 and unchanged predecessor45 theorems.

The actual model experiment found **secret-paired publication-presence differences**
while every published count remained correct. It did **not** find reliable model
execution of the requested deliberate representation or withholding encoders.
Those failed controls remain negative findings. We do not claim a general model
alignment failure, population attack rate or globally novel privacy principle.

The implemented fix commits the public query before private access, keeps proposal
verdicts private, and has the authority compute/commit one canonical approved
answer independently of model content, errors or withholding. **This improves the
restricted release pipeline, not neural intelligence.** Trusted host completion
is required. The output intentionally discloses the approved count or parity;
privacy is equality of public traces for datasets with the same approved view.

## Research and adoption limits

The domain is four binary flags, one hidden bit, and two fixed approved queries.
The unbounded representation-channel theorem concerns repeated stateless verified
claim releases; it does not assert unlimited throughput of a bounded broker.
Canonicalization without trusted completion is insufficient, and private-dependent
query selection remains unsafe. The public query and completion schedule must
belong to the authority. Free-form neural explanations are not verified here.

The compiler, OS/libraries, Python, SQLite and model runtime remain trusted. No
kernel proof refines actual SQL/host behavior or quantized neural numerics. Public
trace equality excludes timing, termination/status, logs and other external
channels. Host crash, failure to finalize, external scheduling, persistent recovery
and rollback of both storage and host checkpoints remain outside the guarantee.
Hashes, sealed snapshots and memory anchors do not create an administrator-proof
root. Research captures contain synthetic private-channel audit data only.

All6,413 predecessor blobs/modes, production PCS authority, PGSI/Aristotle proofs
and earlier evidence are preserved. This is a research-only stacked change;
nothing is merged or deployed. It is suitable for controlled independent replay,
not production confidential-agent adoption. Next: externally anchored completion
and storage, a smaller proved effect adapter, larger approved-query libraries,
and counterbalanced held-out tasks/models with predeclared utility and privacy
criteria.

The information-flow/declassification principle is longstanding. Bibliographic
metadata was checked for Sabelfeld/Myers, [Language-based information-flow
security](https://doi.org/10.1109/JSAC.2002.806121) (2003), and Sabelfeld/Sands,
[Declassification: Dimensions and principles](https://doi.org/10.3233/JCS-2009-0352)
(2009). This is not an exhaustive novelty review or external validation of PCS.
The supported contribution is the new PCS proof/executable contract, its exact
real-model witnesses and limitations, and the independently reproduced quota fix.
