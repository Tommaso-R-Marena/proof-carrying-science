# Independent scientific study review: primary frozen evaluation

This phase implements a reproducible research review tool, not a reliable automatic scientific reviewer. The principal result is a negative one: **neither actual pipeline recovered the independently annotated principal claims under the new strict complete-study protocol**. Conditional biochemical model reconstruction and stronger evidence custody work, but do not establish biological conclusions or general paper understanding.

Draft [PR207](https://github.com/Tommaso-R-Marena/proof-carrying-science/pull/207) is stacked on exact PR203 commit `26a8adda12dbb7fd949f14eeddee3d7d870cadd1`. PR199–203 remain unchanged, unmerged and undeployed. All implementation additions are research-sidecar files plus one additive research CI workflow. Production authority, source-census controls and earlier evidence are unchanged.

## Implemented and executed

- Snapshot-only directory/ZIP review reuses original intake, source digests, provenance, dependency records and parent verification/cache infrastructure. It preserves original artifacts and does not execute uploaded programs or train on uploaded material.
- Typed interpretation adds explicit assumptions, scoped active/passive biological relations, source-backed SBML conditions and unit fields, strict explicit cross-document correspondence, and PDF/DOCX extracted-text bindings. Derived text has adapter/segment provenance; its offsets are not original PDF byte spans.
- Full-key measurement/prediction joins distinguish conditions, observables, time and calibration metadata. Exact decimal residual sums, parameter-domain checks and reference completeness checks are separate from independent model execution.
- A closed SBML L2V4/PEtab reconstruction uses 80-digit initial arithmetic and actual SciPy Radau/BDF integration. Original/projected model hashes, structural changes, conditions, parameter overrides and every prediction are retained. Unsupported features abstain.
- An actual Lean 4.28.0 harness independently compiles nine elementary integer-residual statements and checks the exact source/theorem/axiom census. Python/SBML/Fraction refinement and empirical adequacy remain open.
- Exported reviews distinguish mathematical proof, reproduced computation, checked source statements, refutation and unresolved findings. Replay checks an exact physical package census and independently regenerates authorized v4 checks; nested sources/evidence/authority are compared fully. Missing or forged evidence fails closed.

8. `nonzero_residual_rules_out_zero_sse`

These are elementary known algebraic consequences, not novel mathematical discoveries. The first three audit with no axioms; the remaining six use standard `propext` only. No `sorry`, `admit`, new axiom or `native_decide` is admitted. Exact reviewed source SHA256 is `9400e0afa7e11630c18240e08b61519c8244249cda8db8c824ad41503c07cd7d`. The independent harness rejects modified sources, missing audit declarations, invalid proofs and unavailable compilers.

Key alignment is an explicit premise in the Lean structure. The proofs do not establish correctness of Python key construction, Fraction arithmetic, parsing, unit interpretation, ODE semantics, solver error, source meaning or empirical applicability. Source hashes identify bytes; host custody, compiler integrity and external source authenticity remain assumptions. Permissions, subprocess limits and stripped environments are not a hostile-host security boundary. Uploaded code remains data and has no authority or training path.

Adversarial unit tests cover malformed/ambiguous data, duplicated prediction keys, swapped conditions, extreme arithmetic, namespace collisions, unsupported SBML constructs, fake/nested authority and receipt fields, altered snapshots, extra physical files, symlinks and manifest tampering. A separate four-case campaign modifies actual development source copies, retaining original/derived hashes and complete outcomes in [development-adversarial-numerics.json](evidence/development-adversarial-numerics.json). ## Readiness and next experiment

PCS v4 is suitable for review as an experimental provenance, supported-declaration and conditional-computation assistant. It is not ready to certify unfamiliar complete studies, biological conclusions or arbitrary scientific meaning. Qualified expert adjudication, source-to-code refinement, statistically meaningful scientific reference sets and better explanation/navigation remain necessary.

The highest-value next scientific experiment is **expert-adjudicated, source-anchored relation/equation/assumption recovery on a small set of complete studies**, with identifier-independent but independently checked semantic matching and explicit reviewer questions. Freeze a genuinely new corpus after adjudicating this protocol. Compare deterministic interpretation against a bounded untrusted language-model proposal stage, using the same independent typed/source checks; measure useful answers and unsupported interpretations rather than architecture size. The present final sources are exposed and may only be development/diagnostic material henceforth.

Reproduction commands and exact environments are in [README.md](README.md); complete packets, primary outcomes, source freezes, compiler receipts and test logs are indexed by [experiment-index.json](evidence/experiment-index.json). Original results are retained even if later engineering diagnostics improve availability.
