# Scientific semantics: prospective evidence and unresolved meaning

The new interpreter substantially improves a bounded, source-grounded task. On
fresh final projects it recovers **19/22 core claims and14/22 complete typed/context
claims**, versus **10/22 and5/22** for the unchanged PR202 interpreter under the
same new protocol. This is evidence for better scientific source interpretation
in the implemented fragments, not general scientific intelligence or scientific
discovery. Learned retrieval still does not beat the strongest deterministic
baseline. The final numerical regression remains unsupported in the primary run.

## Exhaustive PR202 failure analysis

`ERROR_ATLAS.md` and its reproducible430KB JSON atlas inspect all41 supported
old probes, all34 misses, all19 old-final misses and12 counterprobes. The full
original grader output reproduces unchanged:6/21 development and1/20 final.
No reference, protocol or original result was rewritten.

Failures mix real missing interpretation/derivation with representation and grading
problems. Examples include reported counts rejected by relation spelling,
inverse-power versus division forms, initial-condition names versus source symbols,
unspecified units versus annotation role labels, missing assumption-sensitive
dimensional inferences, absent ODE call-site links and missing conservation links.
An algebraically equal expression does not automatically share domain, units or
scientific meaning. A genuine unannotated semantic error is retained: `2N`
differential equations became2newtons. Thus grading mismatches do not establish
that the original extractor was scientifically correct overall.

## Implemented improvements

Typed claims now distinguish declared values, author-reported values, initial
amounts/concentrations, parameter estimates/standard deviations, equations,
literal biological identifier names and narrowly explicit scientific predictions.
Case-sensitive model/reaction scopes, local shadowing, symbol references, exact
source byte spans, declared units/scales, domains and dependencies are explicit.
Unknown units, scientific premises and empirical adequacy are never fabricated.

The unchanged v1/v2 stack supplies byte-preserving directory/ZIP intake, all its
format adapters, authenticated parent caching, graph and independent checking.
New semantic processing reads sealed copies of those snapshots. A fixed worker
enforces30CPU seconds,1.5GiB address space, file limits and a45second parent
timeout with process-group cleanup. This is process isolation with resource
limits, not a full OS sandbox or an immutable root.

Independent checkers reparse XML with separate Expat byte-position tracking and
direct mathematical parsing. They check the actual selected declaration, its
identifier, model/reaction scope, role, equation side/relation and original source
span. A digest plus an unrelated true quote cannot establish assertion grounding.
Rational comparison retains nonzero-denominator obligations and remains a Python
computation, not a proved compiler or scientific interpretation.

The numerical checker reconstructs a closed StRD regression fragment without
executing imported code. Float and independent80-digit Decimal calculations are
compared; rational models additionally get exact rational interval enclosures
under explicit last-printed-digit rounding assumptions. Statistical uncertainty
is separate from rounding; optimality, distributional assumptions and empirical
validity are not certified. Transcendental interval bounds are unsupported.

The local CLI generates an understandable HTML review with exact source quotes,
original-file downloads, checked-field details, conditions and unresolved inputs.
There is no deployment or human usability study.

actually a `parameter_std` proposal, not a claim of a confidence interval. These
granularity differences are exposed rather than hidden as universal abstention.
Zero observed promotions is a finite observation under an intentionally denied
scientific-authority interface, not proof of arbitrary scientific understanding.

## Retrieval: gains and a retained generalization failure

The old retriever's0/25 result was reproduced exactly. High scientific vocabulary
mismatch, missing compatible candidate chunks and training/source mismatch are
measured contributors; vector variation does not establish complete collapse.
No new source material became training data and no new JEPA/RL training is claimed.

Identifier normalization, overlapping original-source windows, combined pools and
symbolic features improve diagnostic/development relevance. The selected
development configuration was combined-pool TF-IDF16/28, versus combined BM2510/28
and neural5/28. The selection was frozen before final access.

On fresh final sources the selected configuration reaches20/28. Original-pool
BM25 also reaches20/28, while original-pool TF-IDF and normalized BM25 reach21/28.
Within the same combined pool, BM25 gets16/28, TF-IDF20/28 and neural7/28.
Thus the new pool/selector does **not** surpass the strongest deterministic
baseline prospectively. Every pool/mode ablation is retained. Retrieval relevance
is not entailment, and the live scientific checker never routes around authority.
The research selection is an explicit benchmark configuration; the compatibility
ranking API still requires callers to select the documented mode/pool.

## Cost, adversarial validation and integration risks

CPU-only primary workflow totals:20.15seconds development and16.34seconds final,
including all retrieval ablations and replay. Max parent RSS is about42MiB;
max child high-water is about397MiB in the development process. These are process
high-water measurements, not isolated per-component allocations. No GPU, paid
inference API or imported-source training was used.

The combined local intake/v2/v3 run passes **455 tests and168 subtests**.
The new suite contributes178 tests. The repository integrity audit passes.
The dedicated CI also explicitly runs the unchanged Proof-JEPA and Safety-JEPA
suites, instead of relying on parent workflow path filters.

The authored adversarial campaign improved from21/25 to25/25 after real repairs.
All original failures are preserved. Tests cover namespace smuggling, conflicting
definitions, forged scopes, unrelated quotes, relation/LHS substitution, negated
prose, unit/amount distinctions, exact decimal literals, fabricated evidence,
rollback-style manifest forgeries, dropped checks, symlinks, parser limits and
nonexecution. An independently authored rational interval campaign checks240
cases and49,200 points with no observed enclosure violation. This does not prove
the implementation universally correct.

The cross-stack audit records11 findings over54 predecessor runtime files, seven
duplicate-helper groups, incompatible representations and coarse cache/source
contexts. Two ranking-only checkpoint bugs are reproduced on copies: same-mtime
stale-cache reuse and duplicate JSON keys. A new wrapper pins exact model bytes,
uses bounded no-follow reads and strict JSON. Old files remain unchanged.
Large duplicated parsers should not be blindly merged: some duplication supplies
independent differential checks. Interpreter/checker/evaluator import coupling,
cross-host Python build bindings, lack of OS sandboxing and unaudited scientific
meaning remain important maintenance/adoption limits.

## Reproduction and next scientific milestone

Use `README.md` commands and the exact locks. Original primary packets require
the frozen runtime at `a5de2b0` and matching recorded Python/Lean/library context.
On another compatible installation, a fresh run creates a new explicitly recorded
runtime context; do not bypass a historical receipt mismatch or call a rerun of
exposed final sources fresh generalization.

PCS is now more useful for reviewing supported scientific encodings and numerical
reports, with meaningful source fidelity and transparent uncertainty. It is not
ready to certify arbitrary papers or empirical conclusions. The highest-value
next experiment is qualified domain-expert annotation of a new full open-access
paper/data/code project, with source-to-code roles, uncertainty and biological
interactions prospectively adjudicated. Additional neural complexity is not
currently supported by the evidence.
